# 🍽️ El Real — Menú Digital

Menú digital interactivo para el restaurante **El Real**, con panel de administración para gestión de productos. Desplegado en GitHub Pages.

🔗 **[Ver menú en vivo](https://agenciaseniors.github.io/el-real/)**

## ✨ Características

- 📋 Menú visual con categorías y filtros
- - 🔐 Panel de administración con autenticación Firebase
  - - ➕ CRUD completo de productos (crear, editar, eliminar)
    - - 📱 Diseño responsivo para móviles y escritorio
      - - ⚡ Despliegue automático en GitHub Pages
       
        - ## 🛠️ Tecnologías
       
        - | Tecnología | Uso |
        - |---|---|
        - | HTML5 + CSS3 | Estructura y estilos |
        - | JavaScript | Lógica de la app |
        - | Firebase Auth | Autenticación del admin |
        - | Firebase Firestore | Base de datos en tiempo real |
        - | GitHub Pages | Hosting gratuito |
       
        - ## 🚀 Uso
       
        - 1. Abre el [menú en vivo](https://agenciaseniors.github.io/el-real/) para ver la carta
          2. 2. Accede a `/login.html` con credenciales de admin para gestionar productos
             3. 3. Agrega, edita o elimina platos desde el panel admin
